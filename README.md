Un bot de Discord **modular y completo**, diseñado para FlowMC con múltiples sistemas como **sorteos, sugerencias, encuestas, actualizaciones y más**. Ideal para administradores que buscan automatizar la gestión y mejorar la interacción con sus miembros.

---

## ✨ Características Principales

| Sistema | Funcionalidad |
|---------|---------------|
| 🎉 Sorteos | Crear sorteos con persistencia automática y restauración al reiniciar |
| 📝 Sugerencias | Sistema de votación con aprobación/denegación por administradores |
| 📊 Encuestas | Crear encuestas personalizadas con emojis y votación |
| 📢 Actualizaciones | Publicar cambios del servidor con formato y colores personalizados |
| 🎮 Estado Rotativo | Estados del bot que muestran info de Discord y Minecraft en tiempo real |
| 👋 Bienvenidas | Mensajes personalizados para nuevos miembros |
| 💎 Boosts | Notificaciones cuando alguien impulsa el servidor |
| 🛒 Tienda (Tebex) | Webhooks para notificar compras en tiempo real |
| 🔧 Modularidad | Sistema de habilitación/deshabilitación de módulos sin reinicio |
| 💾 Persistencia | Datos guardados en archivos JSON (sin base de datos necesaria) |
| 🔒 Seguridad | Permisos de roles configurables y validaciones |
